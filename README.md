# E-Commerce API Backend

A robust RESTful API backend for an e-commerce platform built with Django and Django REST Framework. This project features comprehensive product and category management with advanced filtering, secure user authentication with JWT, cart functionality, and multi-image uploads with automatic thumbnail generation. It is fully production-ready, featuring PostgreSQL integration, WhiteNoise for static file serving, and S3-compatible cloud storage (Supabase) for media, all configured for seamless deployment on Render.
